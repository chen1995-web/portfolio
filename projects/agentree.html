Agentree — a multi-agent framework that spawns sub-agents

Give an agent a task and it can recursively spawn sub-agents to tackle parts of it. Each sub-agent runs in its own context — the parent only sees the final output. A persistent team system mirrors how real agent teams collaborate: teammates, an inbox, a shared task board with dependencies.

Python · FastAPI recursive spawn context isolation team system 28 tests ✓ Vue 3 dashboard

01. The idea

Single-agent loops stall on long, parallelizable work. Agentree lets an agent decompose a task and fan out to sub-agents, each running the same Agent loop with its own tools, steps, and context. Three guardrails — max_depth, max_steps, max_children — cap runaway recursion and token cost.

02. The agent tree

A parent task fans out to parallel children; a child can itself spawn grandchildren (depth 2), still bounded by the same limits. Tool results are truncated before backfill so a single runaway call can't blow the parent's context.

03. It's real — screenshots

The web dashboard (Vue 3 + Element Plus) shows the live agent tree as runs progress, plus a real-time event stream.

04. Core API

run_agent(task, config, …)

Run an agent to a final answer. With spawn tools available, children recurse through this same function.

Team(emit, client)

A persistent team: await team.run("task"). Lead coordinates teammates via a shared task board.

@tool(name, description, parameters)

Register a custom tool. Tool descriptions are model-facing — you control what the agent can do.

AgentConfig

max_depth=2 · max_steps=30 · max_children=8 · enable_web=True.

06. Run it

Zero-cost, runs locally. Any OpenAI-compatible gateway works.

# deps pip install fastapi uvicorn numpy scikit-learn # point at your LLM gateway export AGENTREE_API_KEY=sk-... export AGENTREE_BASE_URL=http://127.0.0.1:3065/v1 export AGENTREE_MODEL=deepseek-v4-flash export AGENTREE_DEMO_AUTH=on # web server (dashboard on http://127.0.0.1:8767) python3 -m agentree.server --port 8767 # or the CLI python3 -m agentree.cli "summarize this doc" # tests — 28 passing python3 -m pytest tests/ -q -p no:asyncio # or ship it as a container (multi-stage: builds the Vue frontend, serves via uvicorn) docker build -t agentree . docker run -p 8767:8767 agentree # → http://127.0.0.1:8767 (demo mode on by default)

Deployment-verified: the Dockerfile above was built and run end-to-end (image 181MB, frontend compiled in-container, API serving, demo login returning tokens). It's a real deployable, not a README claim.

07. Design decisions

Trade-offWhy
Recursion over frameworksOne Agent loop, reused at every depth — no combinatorial explosion of code paths.
Context isolation per childParent stays lean; a child's tool noise never leaks into the orchestrator.
Truncate tool resultsBounds tokens on the hot path — the #1 cost/latency killer in agent loops.
Team mirrors real teamsPersistent teammates + shared task board = the pattern production agent teams already use.
Zero-cost defaultRuns on a local gateway; no cloud bill to demo.
