RAG · Document Q&A

RAG Doc Chat — drop a PDF, get cited answers

Point it at a folder of documents, ask a question, get an answer with the exact source cited. The twist: hybrid search (vector + keyword) beats pure vector search by 10% hit@1 — measured, not claimed.

hit@1 +10% hybrid (vector + BM25) local feature-hash embeddings 0-key demo FastAPI

01. Why hybrid beats pure vector

Pure vector search is great for paraphrase but weak on exact names, codes, and numbers. Adding keyword (BM25) search and fusing the two scores fixes that. On a 5-doc, 20-question eval:

MetricVector onlyHybridDelta
hit@118 / 2020 / 20+10.0%
hit@319 / 2020 / 20+5.0%
hit@520 / 2020 / 200.0%

The gains come from the top-1 tier — exactly where a wrong answer costs the most. Retrieval is retrieve.py, fusion is a simple RRF (reciprocal rank fusion).

02. Zero-key demo

Embeddings use a deterministic local feature-hash (no API call), and answers are extractive by default — so the entire pipeline runs with no LLM key. Drop in a real key for generative answers.
